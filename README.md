# Crossplane

Crossplane is a framework for platform engineers to build sustainable platforms for the developers.

In this lab, I will learn:

- What problem does Crossplane solve?
- Why should a company use Crossplane?
- How does one design Crossplane to comply with best practices?
- When should a Platform Engineer start to learn Crossplane?
- Who should learn Crossplane?

## Technology

The lab uses virtual machines based on KVM to create the Kubernetes cluster. The cluster creation and configuration is performed with K3s and Ansible. The environment is largely automated with scripts and reusable as a general Kubernetes environment, not only for Crossplane.
